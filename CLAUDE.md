# MotoMaster Claude Instructions

## Project Context

MotoMaster is a web-based automotive repair simulation and performance tracking platform.

## Technologies

Python, Flask, Three.js, JavaScript, HTML, CSS, Bootstrap, MySQL, and Blender.

## Coding Guidelines

- Keep code simple and understandable.
- Reuse existing components when possible.
- Avoid unnecessary dependencies.
- Preserve existing database relationships.
- Use descriptive variable and function names.
- Test features after making changes.

## 3D Simulation

Three.js handles:
- Vehicle models
- Camera controls
- Raycasting
- Object interaction
- Animation
- Repair-tool interaction

## Performance Tracking

The system tracks:
- Completion time
- Accuracy
- Errors
- Task completion
- Scores
