# MotoMaster Project Knowledge

## Project
MotoMaster is a web-based 3D vehicle repair simulation and performance tracking platform for auto-mechanic education.

## Technologies
- Python / Flask
- Three.js
- JavaScript
- HTML/CSS
- Bootstrap
- MySQL
- Blender

## Main Modules
- Engine Oil Change
- Brake Pad Replacement
- Air Filter Replacement
- Fuel Filter Replacement
- Battery Maintenance
- Spark Plug Replacement

## Users
- Student
- Instructor
- Admin

## Important
The project uses Three.js for interactive 3D vehicle simulations and Python/Flask for backend processing and performance tracking.
