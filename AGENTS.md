# MotoMaster Agents Guide

## Project Rules

1. Use the existing project structure whenever possible.
2. Do not remove existing functionality without permission.
3. Use Three.js for 3D vehicle interaction.
4. Use Python/Flask for backend logic.
5. Use MySQL for persistent data.
6. Keep student performance records accurate.
7. Follow the existing UI design and coding style.
8. Test changes before committing.

## Development Focus

Prioritize:
- 3D vehicle interaction
- Automotive repair simulations
- Student performance tracking
- Scoring and evaluation
- Clean and responsive UI
