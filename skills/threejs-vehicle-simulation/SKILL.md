# Three.js Vehicle Simulation Skill

## Purpose
Help develop interactive 3D vehicle repair simulations using Three.js.

## Responsibilities
- Load GLB/GLTF vehicle models
- Implement camera controls
- Implement raycasting
- Detect interactive vehicle components
- Create repair animations
- Handle tool interactions
- Manage 3D object visibility and movement

## Project Context
MotoMaster uses Blender for 3D modeling and Three.js for web-based simulation.

## Guidelines
Keep interactions simple, responsive, and understandable for automotive students.
