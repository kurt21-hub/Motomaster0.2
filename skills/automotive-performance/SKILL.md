# Automotive Performance Skill

## Purpose
Help develop student performance tracking and evaluation features for MotoMaster.

## Responsibilities
- Track completed tasks
- Record completion time
- Record errors
- Calculate scores
- Track accuracy
- Generate performance summaries

## Project Context
MotoMaster evaluates students while they perform simulated vehicle repair procedures.

## Guidelines
Use clear and consistent scoring rules. Store important performance data in MySQL and process evaluation through the Python/Flask backend.
